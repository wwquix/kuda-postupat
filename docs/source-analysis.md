# Анализ источника БГЭУ

Проверено 12 июля 2026 года прямыми HTTP-запросами, без браузерной автоматизации.

## Что найдено

Страница `https://bseu.by/abiturient/` отвечает `200 OK` и отдает небольшой статический HTML. В нем нет таблиц (`<table>` отсутствует). Заголовок и meta-тег объявляют `windows-1251`; фактический HTML также декодируется как Windows-1251. Страница подключает `abit.js`, задает `xmlpath='xml/'` и вызывает `shsp()`.

`abit.js` выполняет обычный `XMLHttpRequest GET` к пути, который строится как `xml/<id>.xml`. При начальной загрузке вызывается `xmlHttpObject(1)`, то есть реальный источник текущей конкурсной ситуации:

`https://bseu.by/abiturient/xml/1.xml`

Endpoint отвечает `text/xml`, использует XML-декларацию UTF-8 и на момент проверки содержал `DATAPACKET / ROWDATA / ROW` с 77 строками. Сервер также прислал `ETag` и `Last-Modified`; монитор использует их в условных запросах.

## Схема конкурсных строк

Данные передаются атрибутами `ROW`:

- `spname` — специальность;
- `frname`, `frmid` — форма обучения;
- `IDFINANCE` — основа (`18` — бюджет, `19` — платная);
- `PlanBudj`, `PlanVneBudj` — планы бюджетного и платного приема;
- `AllCount` — число заявлений;
- `genTime` — время обновления источника;
- `G_Less_70`, `G_71_75`, ..., `G_396_400` — распределение по диапазонам баллов.

В одном XML присутствуют дневная бюджетная, дневная платная, заочная, заочная сокращенная и дистанционная формы. Отдельные HTML-страницы для форм не нужны: фильтрация выполняется по `frname`/`frmid` и `IDFINANCE`. На момент проверки «Экономическая информатика» присутствовала двумя дневными строками — бюджетной и платной.

## Защита от неверного источника

Это именно страница текущих «сведений о поданных документах», а не архив итоговых проходных баллов. Парсер требует `DATAPACKET`, конкурсные `ROW`, обязательные именованные атрибуты и распределение `G_*`. Пустая страница, исторический HTML или измененная схема приводят к явной ошибке; предыдущий корректный snapshot сохраняется.

Браузер и Playwright не используются, поскольку XML полностью доступен обычным HTTP-запросом.
